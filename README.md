# 전국 상세 날씨 정보판 v5

## v5 변경점
상단 카테고리형 네비게이션으로 화면을 나눴습니다.

메뉴:
- 홈
- 현재 날씨
- 시간별 예보
- 7일 예보
- 기록 · 비교
- 데이터 정보

실제 HTML 파일을 여러 개 만드는 대신 한 페이지 안에서 탭처럼 화면을 전환합니다.
그래서 선택한 지역과 불러온 날씨가 메뉴를 이동해도 그대로 유지됩니다.

## 추가 기능
- 홈 대시보드
- 앞으로 6시간 강수확률 미리보기
- 앞으로 24시간 시간별 강수확률 카드
- 상세 시간표
- 7일 예보
- 현재 날씨 상세 지표
- 하루 한 번 기록
- 이전 기록 비교
- 원자료 URL 및 조회시각
- 지역 선택 상태 localStorage 유지

## 실행
Docker는 필요 없습니다.

1. 압축을 풉니다.
2. index.html을 실행합니다.
3. 인터넷 연결이 되어 있으면 행정구역 및 날씨 데이터를 가져옵니다.
4. GitHub Pages에 올리면 제출용 웹 주소로 바로 사용할 수 있습니다.

## 출처
- 날씨: Open-Meteo Forecast API
- 행정구역: mapcn-kr / admdongkor
